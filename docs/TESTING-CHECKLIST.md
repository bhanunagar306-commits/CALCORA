# CALCORA QA checklist

- [ ] Test on Chrome, Edge and Firefox desktop.
- [ ] Test Android/iOS browser layouts and PWA installation.
- [ ] Verify offline launch after first successful load.
- [ ] Test keyboard navigation and screen-reader announcements.

- [ ] Confirm temperature conversions around absolute zero.
- [ ] Verify percentage convention meets target-user expectations.
- [ ] Check GitHub Pages deployment under a repository subpath.
- [ ] Replace generic contact text in privacy policy with maintainer contact details before Store submission.
